# Доки

**Открыли. Подписали. Отправили.**

PDF на Android без лишнего. Подпись пальцем или с фото, текст поверх, сохранение в тот же файл.

Бесплатно · Без рекламы · Открытый код · Android 6+

## Зачем

Подписать PDF на телефоне должно быть просто. Без окон, рекламы и подписок.
И чтобы «Поделиться» отправляло файл, а не ссылку.

## Что умеет

**Читать**
- PDF, Word, Excel, PowerPoint, OpenDocument, RTF, CSV, TXT.
- Поиск, выделение и копирование текста.
- Текст со сканов распознаётся прямо на телефоне.
- Ночной режим: страница тёмная, фото как есть.

**Править PDF**
- Подпись, текст поверх, заметки.
- Маркер, подчёркивание, зачёркивание.
- Рисование, фигуры, стрелки.
- Правка текста самого PDF, его же шрифтом.
- Заполнение форм.

**Страницы и файлы**
- Склеить, разделить, вынуть страницы.
- Повернуть, удалить, переставить.
- Сжать, поставить или снять пароль.
- Номера страниц и водяной знак.
- Страницы в картинки, текст из PDF.

**Таблицы и документы**
- Excel (XLSX): правка ячеек и сохранение.
- Word и PowerPoint: просмотр и экспорт в PDF.

**Скан и картинки**
- Скан бумаги в PDF, сразу много страниц.
- Обрезка, выравнивание, фильтры, удаление фона.

**Создать PDF**
- Из фото, текста, HTML или сайта.

## Основа

Форк [ClearPDF](https://github.com/Chethan616/ClearPDF) от Chethan616. Просмотр, редактор
и сканер — оттуда.

Своё имя, потому что дорабатываем быстро и без согласований. Удачное предлагаем
в ClearPDF, принимать или нет — решает его автор.

## Что дорабатываем

**Подписи**
- [x] Подпись с фото: фон убирается, остаются чернила.
- [x] Цвет подписи: как на фото или свой.
- [x] Пропорции сохраняются при растягивании.
- [x] Рамка ровно по подписи.
- [ ] Копия подписи того же размера.
- [ ] Инициалы.

**Документ**
- [x] Русский текст сохраняется, без «???».
- [x] «Сохранить» рядом с «Поделиться».
- [x] Сохранение в тот же файл.
- [ ] Копировать и удалять прямо над выделенным.

## Приватность

Всё на телефоне. Без аккаунтов, рекламы и аналитики.
В сеть — только по вашей команде: движок для Office или PDF из сайта.

Сканер и распознавание текста — Google ML Kit. Документы не уходят, но Google получает
статистику работы модулей. Без этого — сборка `fdroid`.

## Сборка

JDK 21 и Android SDK 36.

    ./gradlew :app:assembleFossDebug     # с Google ML Kit
    ./gradlew :app:assembleFdroidDebug   # без Google

Ставится рядом с ClearPDF, данные отдельные.
